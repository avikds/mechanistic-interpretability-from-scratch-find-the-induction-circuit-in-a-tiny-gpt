# mechanistic-interpretability-from-scratch-find-the-induction-circuit-in-a-tiny-gpt
Induction heads are the first circuit anyone found inside a transformer and still the cleanest: a previous-token head in one layer writes 'the token before me was X' into the residual stream, and an induction head in the next layer reads that write to look up what followed X last time, then copies it.
